Resale Cert CRM Helper

A Chrome extension that removes repetitive data entry from every customer page in the resale CRM.

  • RoleDesign & build, from scratch
  • TypeBrowser extension
  • StackChrome extension · JavaScript · DOM
The problem

The same fields, every page, by hand.

Every customer page in the resale CRM required the same steps: fill in the known fields, copy the data needed for the next form. Small amounts of time per page, repeated constantly through the day.

Individually each step is nothing. Collectively it's work that adds no value, the kind that hides in plain sight because it's always been there.

The approach

A small tool for a small, expensive task.

A Chrome extension that watches the customer page and handles the repetitive steps automatically: known fields get filled, and the data needed next is copied to the clipboard.

Plain JavaScript and DOM-aware field detection, nothing else. Lightweight by design, because a tool that slows the page down would be a different kind of waste.

The build

How it was built

  • A Chrome extension in plain JavaScript, no dependencies.
  • DOM-aware field detection instead of fragile hardcoding.
  • Auto-fill and clipboard copy, one less manual step per page.
  • Quiet by design: no UI clutter, no popups.
The outcome
What changed

Less typing and fewer mistakes. The page work happens automatically, so the person moves on to the next customer.
