Sourcing & Pre-Canvassing System

A sidebar tool for supplier sourcing: seller records, spending, and CRM-ready notes in one repeatable workflow.

  • RoleDesign & build, from scratch
  • TypeInternal sourcing tool
  • StackApps Script · Sidebar UI · Sheet integration
The problem

A spreadsheet that grew without rules.

Supplier sourcing ran on a sheet where records had accumulated in different formats. Seller details lived wherever someone happened to put them, spending wasn't tracked, and writing CRM notes meant copying fields one by one.

Every new supplier meant the same slow, error-prone loop, and follow-ups were easy to miss.

The approach

Standardize the flow, not the people.

  • Save. Seller details are captured consistently, in one format.
  • Track. Spending per source, visible at a glance.
  • Hand off. One click generates a CRM-ready note; no field-by-field copying.

The sidebar adapts to the sheet layouts already in use, so new suppliers slot in without restructuring anything. The tool bends to the data, not the other way around.

The build

How it was built

  • A custom sidebar interface inside Google Sheets.
  • Seller records keyed consistently, whatever format they arrived in.
  • Per-source spending tracking.
  • One-click CRM note generation from the record.
  • Header mapping that adapts to existing sheet layouts.
The outcome
What changed

One consistent sourcing workflow: cleaner records, less copy-paste, and follow-ups that don't get missed.
